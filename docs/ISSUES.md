# Issues

Search existing issues before opening a new one. If you find the same problem or request, add useful details there instead of opening a duplicate.

## Open an issue

For a bug, describe what you expected, what happened, and how to reproduce it. Include the mod version, Minecraft environment, and relevant log lines when available. Remove account details or other private information from logs before posting them.

For a feature or improvement, describe the problem it would solve and the result you expect. A short example helps, but you do not need to design the implementation. Questions and early ideas are welcome too.

You do not need to choose every label. Maintainers can add or change labels as the issue becomes clearer.

## Triage

While looking into an issue, maintainers may add https://github.com/12src/12pit/labels/needs%20triage, https://github.com/12src/12pit/labels/needs%20info, or https://github.com/12src/12pit/labels/needs%20reproduction. Use https://github.com/12src/12pit/labels/needs%20decision or https://github.com/12src/12pit/labels/discussion for open product or technical questions, https://github.com/12src/12pit/labels/question for usage questions, and https://github.com/12src/12pit/labels/invalid when the premise is incorrect or the issue is outside the project scope.

Mark an issue https://github.com/12src/12pit/labels/confirmed once a problem is reproduced or a request is accepted. You can then classify it by type, area, priority, and environment. Use https://github.com/12src/12pit/labels/needs%20verification for a proposed change until someone checks it in the game or affected environment.

Some issues end after an answer or discussion. Others may be closed as https://github.com/12src/12pit/labels/duplicate, https://github.com/12src/12pit/labels/cannot%20reproduce, https://github.com/12src/12pit/labels/upstream, or https://github.com/12src/12pit/labels/wontfix.

## Labels

Use https://github.com/12src/12pit/labels/feature or https://github.com/12src/12pit/labels/enhancement for new requests. Use https://github.com/12src/12pit/labels/bug, https://github.com/12src/12pit/labels/crash, https://github.com/12src/12pit/labels/regression, https://github.com/12src/12pit/labels/compatibility, or https://github.com/12src/12pit/labels/performance for problems. A change may also carry https://github.com/12src/12pit/labels/breaking%20change.

Use https://github.com/12src/12pit/labels/documentation, https://github.com/12src/12pit/labels/refactor, https://github.com/12src/12pit/labels/chore, or https://github.com/12src/12pit/labels/clean for other work.

Domain labels show which part of the project an issue affects: https://github.com/12src/12pit/labels/domain%3A%20CI, https://github.com/12src/12pit/labels/domain%3A%20build, https://github.com/12src/12pit/labels/domain%3A%20dependencies, https://github.com/12src/12pit/labels/domain%3A%20release, https://github.com/12src/12pit/labels/domain%3A%20testing, https://github.com/12src/12pit/labels/domain%3A%20architecture, https://github.com/12src/12pit/labels/domain%3A%20tooling, https://github.com/12src/12pit/labels/domain%3A%20localization, https://github.com/12src/12pit/labels/domain%3A%20licensing, https://github.com/12src/12pit/labels/domain%3A%20governance, and https://github.com/12src/12pit/labels/domain%3A%20UI%2FUX.

Priority labels show how soon work should be addressed: https://github.com/12src/12pit/labels/priority%3A%20P0, https://github.com/12src/12pit/labels/priority%3A%20P1, https://github.com/12src/12pit/labels/priority%3A%20P2, and https://github.com/12src/12pit/labels/priority%3A%20P3.

Environment labels show where an issue occurs: https://github.com/12src/12pit/labels/env%3A%20Windows, https://github.com/12src/12pit/labels/env%3A%20Linux, https://github.com/12src/12pit/labels/env%3A%20macOS, https://github.com/12src/12pit/labels/env%3A%20mod%20conflict, and https://github.com/12src/12pit/labels/env%3A%20server-specific.

An issue may also be https://github.com/12src/12pit/labels/blocked or marked as a https://github.com/12src/12pit/labels/release%20blocker.

## Pick an issue

The https://github.com/12src/12pit/labels/help%20wanted label means community contributions are welcome. Start with an open issue marked https://github.com/12src/12pit/labels/confirmed. For a smaller first task, look for https://github.com/12src/12pit/labels/good%20first%20issue. Check that no one else has claimed it, then follow the [contributing guide](CONTRIBUTING.md) and open a draft pull request.
